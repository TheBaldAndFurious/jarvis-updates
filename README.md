# Remy — private Discord voice assistant

Remy runs on your Windows PC and joins your Discord voice channels. Each installation uses its owner’s Discord and OpenAI accounts, chosen name and voice, and spending limits. Personal and friend installations share the same features.

## Install

Open the [latest release](https://github.com/TheBaldAndFurious/remy-updates/releases/latest) and download the Windows installer. New Remy releases use the Remy-named download. The included setup guide walks through your own accounts, bot picture, wake phrase, voice, sounds and spending limits.

## Update and personalize

With automatic updates enabled, use `/voice update` in Discord or wait for the normal background check. Updates wait for a quiet minute, verify the publisher signature and preserve settings and spending history. A failed startup restores the previous program files.

Open **Set up Remy → Name, wake & voice** to change your bot’s displayed name, picture, wake phrase or sensitivity. Stop the assistant before testing or saving, then start it again. Existing chosen bot names are preserved by the project rename.

## Compatibility

This repository was renamed in place so existing update links continue working. Older releases, internal signed identifiers and a legacy-named installer download remain available for installed update hosts. Use the primary Remy download for new releases.

## Accounts and privacy

No accounts, passwords, API keys, private settings, recordings or spending history are distributed here. Ordinary chatter is processed locally for wake detection; addressed questions use the installation owner’s AI account. Each owner chooses their own daily and monthly spending limits.
